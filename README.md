# مطبخ البنات

لعبة مطعم ومطبخ عربية (RTL) تعمل دون إنترنت داخل تطبيق أندرويد.

## الأقسام

1. تحضير الأطباق والابتكار — صينية المكونات، ابتكار طبق، وصفات اليوم، تقطيع، طهي، تزيين، تقييم.
2. المخزن والكهرباء — القواطع، المخزن، الثلاجة، الفريزر، التوابل، غسالة الصحون، قائمة التسوق، إعادة التدوير.
3. ديكور المطعم — الحمامات، الكراسي، زينة الطاولات، الأجهزة، الحوض، الرخامة، الأثاث، الإضاءة، ركن القهوة، التصوير.
4. الطاولات والزبائن — التوزيع، الطلبات، VIP، الجلوس والمغادرة، الطاقم، التقييم العام، التعليقات.
5. التحديات — الشيف الصغير، التحديات اليومية، تزيين الكيك، الطبخ الجماعي، الإنجازات، الرسائل.
6. التسوق — الأدوات، ترقية الأجهزة، أزياء الشيف، ورشة الأفكار.
7. القصة والمجتمع — القصة، دفتر الوصفات، رسائل الزبائن، حفل الافتتاح، التوظيف، الكاشير.
8. الفروع الدولية، 9. الحفلات، 10. الحيوانات الأليفة، 11. الميني جيمز، 12. الأزياء، 13. الكاميرا،
14. الموسيقى، 15. وصفات الجدة، 16. التوصيل، 17. الهدايا، 18. الإعدادات، 19. الحديقة،
20. إعادة التدوير، 21. أزياء الطاقم، 22. اللعب الجماعي، 23. المشروبات، 24. المكافآت اليومية،
25. معمل النكهات، 26. الروبوت المساعد، 27. الطقس، 28. الإحصائيات.

## التقنية

- WebView + HTML/JS/CSS في ملف واحد، حفظ التقدم في localStorage.
- صوت محلي عبر TextToSpeech العربي، ومؤثرات صوتية من assets/sfx.
- بناء APK تلقائي عبر GitHub Actions على كل دفعة إلى main، ونشره في وسم latest.
